# The Worst Line an AI Could Say

Imagine an AI asking someone out the only way it knows how: it has studied 10,000 conversations, it has run the numbers, and it is 94% sure you will enjoy dinner with it — so please confirm your availability. Confident, polite, and completely missing the point. That is the whole entry.

## How to run

```sh
python3 main.py
```

The script gathers any rule violations first (empty line, over the 140-character cap, or a line break), reports them together, and otherwise writes the line as UTF-8 to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if that variable is unset). Standard library only; output is deterministic.
